Suppression des données utilisateur

Application : Sondage MJ (jugement majoritaire)

Dernière mise à jour : mai 2026

1. Données concernées

Si vous vous êtes connecté via Meta (Facebook) pour voter, nous pouvons détenir :

  • votre identifiant Facebook (lié au sondage) ;
  • votre nom affiché (mode votant public) ;
  • votre bulletin de vote et la preuve de participation ;
  • données techniques (horodatage, identifiant de sondage).

2. Supprimer l’accès Facebook à l’application

Vous pouvez retirer l’application depuis votre compte Facebook : Paramètres Facebook → Applications et sites web, puis supprimer « Sondage MJ » (ou le nom de l’app configurée dans Meta Developers). Cela révoque l’accès OAuth futur ; cela ne supprime pas automatiquement les votes déjà enregistrés.

3. Demander la suppression de vos données côté sondage

Envoyez une demande par e-mail à l’administrateur de l’application en indiquant :

  • l’objet : Suppression de données — Sondage MJ ;
  • l’identifiant ou le titre du sondage concerné (si connu) ;
  • le nom affiché lors du vote ou l’e-mail du compte Facebook utilisé.

Contact : gcgmtnlou at mozmail dot com

4. Délai de traitement

Nous traitons les demandes dans un délai maximal de 30 jours. Vous recevrez une confirmation une fois la suppression effectuée.

5. Effet sur les résultats

La suppression de votre vote peut recalculer les résultats agrégés du sondage si la demande est acceptée et techniquement possible sans compromettre l’intégrité du scrutin en cours.
